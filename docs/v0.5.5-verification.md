# v0.5.5 发布验证

发布日期：2026-10-15。

- 源码标签：`v0.5.5`，应用提交 `72248b9`，位于 main 历史中。后续 `099cdf0` 为首个 fork 发布补充从已有标签手动运行的入口，没有移动标签。
- [Release 发布流程](https://github.com/userSywang/lolPing/actions/runs/38711977817)成功；Windows/macOS 均通过类型检查、原生辅助程序测试、744 项 TypeScript 回归测试和安装包构建；macOS 通过应用签名验证。
- [正式 Release](https://github.com/userSywang/lolPing/releases/tag/v0.5.5)公开且不是预发布，包含 Windows exe、blockmap、latest.yml 和 arm64 dmg。更新信息中的版本、exe 文件名及大小与 GitHub 资产一致。
- 本地生产构建和网站构建通过。实际 Electron 隔离窗口验证小气泡输入、两种通道设置、独立公告替换/计时、字号缩放、输入法保护，以及安装版更新入口和显示的更新来源。
- 使用 `tools/smoke-update.cjs`，在独立配置中模拟当前版本 0.5.4，通过真实 GitHub 更新源检查，结果为 `available: 0.5.5`，说明链接为本项目的 v0.5.5 Release。该测试不下载、不安装，不改变用户正在使用的版本。
- Windows 桌面交付包为同一标签源码的本机构建，复制后 SHA-256 校验一致。GitHub 发布包由 CI 独立构建，因此文件摘要可与本机构建不同；自动更新下载时仍以 GitHub Release 对应 latest.yml 的 SHA-512 校验。

旧定制版曾关闭更新器，需要手动安装 v0.5.5 一次。此后的正式 Release 可通过软件内检查并由用户选择更新。
