# 小气泡输入与独立公告通道

版本：0.5.4-chatmodes.1。替代 0.5.3 的大输入页面。

## 已确认的交互

- Ctrl+Alt+Enter 在鼠标附近呼出一个透明猫猫小输入窗。窗口随字号缩放，可拖动顶部，框内切换随机悄悄话/固定公告，并记住上次选择。
- Enter 发送后收起，Shift+Enter 换行，Esc 丢弃草稿并收起；中文输入法确认候选词不会触发发送。
- 设置 → 悄悄话直接展示两个通道的开关、字号、颜色、透明度、显示时长和快捷样式。设置影响本机收到及自己发送的显示。
- 悄悄话默认屏幕内随机，也可选择本机鼠标附近；默认 6 秒，范围 3–15 秒，最多同时三条。
- 公告固定显示，每位发送者保留自己的最新一条，互不替换；新公告重新计时。默认 60 秒，范围 5–600 秒。固定区域通过左右/上下设置调整，多人自动排列，选择合适列数，空间不足时整体等比缩放，避免遮挡和超出屏幕。
- 两条通道独立启用、独立计时、可以同时显示。Ctrl+Alt+Backspace 收起输入窗并清除全部文字。

## 兼容性与隐私

普通悄悄话沿用 `chat` 包；公告使用独立 `announcement` 包及 presence 的 `bulletin: 1` 能力声明。发送公告要求至少一位支持公告的在线成员。旧版忽略公告，不会将其误显示成普通文字。

两个通道均复用现有房间 AES-256-GCM 认证加密、房间密钥派生、重放保护、静音和速率限制。服务器只能转发密文，无法获取正文；房间码持有者和接收设备仍能解密。正文、草稿不写入设置或聊天记录。服务器仍可见连接地址、时间及流量大小，详见 private-chat.md。

公告是临时消息，不在新成员入房或程序重启后补发。时长和样式由接收端本机设置决定。

## 验证

新增回归覆盖按发送者替换、独立计时与重新计时、随机消息数量上限、通道开关、多人不重叠排列、协议能力校验和公告加密。真实 UDP 双客户端及模拟中继使用真实加密传输验证公告往返。隔离 Electron 运行验证设置控件、小窗尺寸、通道选择保存、字号缩放、两类消息同时存在、公告替换、实际到时清除和输入法保护；隔离测试不改动用户运行配置。
